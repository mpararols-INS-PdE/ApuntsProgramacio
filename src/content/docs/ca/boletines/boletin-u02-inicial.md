# 📝 Butlletí U02 — Inicial

> Sense solucions. Sense presses. Amb un editor de text i moltes ganes de compilar. Això només comença. Comenta les solucions al fòrum i intenta ajudar als companys a què milloren les seves capacitats com a programador.

---

## Exercici 1: Desordena això

Les línies d'aquest programa estan desordenades. Ordena-les per a formar un programa Java vàlid que compili i s'executi:

```java
}
    public static void main(String[] args) {

    }
```

---

## Exercici 2: Què imprimeix?

Sense executar, escriu la sortida exacta d'aquest programa:

```java
public class Escapista {
    public static void main(String[] args) {
        System.out.print("Dijo: \"Java mola\"");
        System.out.println(" y siguió: \tprogramando.");
    }
}
```

💡 **Pista important**: `\"` imprimeix una cometa doble literal, `\t` és un tabulador.

## Exercici 4: La teva fitxa personal

Escriu un programa anomenat `FichaPersonal.java` que mostri el següent text per pantalla:

```
Nombre: [El teu nom]
Edad: [La teua edat]
Lenguaje favorito: Java
¿Emocionado?: true
```

Usa una línia `System.out.println` per a cada camp i assegura't que els booleans (com `true`) no porten cometes.

## Exercici 6: Emparella conceptes

Relaciona cada concepte de l'esquerra amb la seva definició de la dreta:

| Concepte | Definició |
| --- | --- |
| 1. `class` | A. Punt d'entrada del programa |
| 2. `main` | B. Imprimeix text i salta de línia |
| 3. `System.out.println` | C. Defineix un nou tipus de dades o plantilla de codi |
| 4. `//` | D. Comentari d'una línia |
| 5. `args` | E. Conté els arguments de la línia d'ordres |

Escriu les respostes amb el format: 1→C, 2→A, ...

## Exercici 7: El detectiu d'errors

El següent codi té un error de sintaxi que impedeix que compili. Troba'l i corregeix-lo:

```java
public class Detective {
    public static void main(String[] args) {
        System.out.println("Soy un detective")
        System.out.println("y resuelvo errores");
    }
}
```

Escriu la versió corregida. Després, executa-la en VS Code i comprova que funciona.

## Exercici 8: La teva biografia

Escriu un programa anomenat `Biografia.java` que mostri:

- El teu nom
- La teva edat
- El teu llenguatge de programació favorit
- Una frase que et motive

Cada dada ha de sortir en una línia diferent, però amb una única condició: usa una sola instrucció `System.out.println` utilitzant `\n` per als salts de línia.
